# Баланс игры

## Обзор документа

Этот документ содержит подробную информацию о балансе игры, включая характеристики оружия, параметры врагов и формулы расчёта урона.

---

# Система баланса

## Основные принципы

1. **Камень-Ножницы-Бумага**: Каждый тип оружия эффективен против определённых типов врагов
2. **Прогрессия**: Оружие становится сильнее с прогрессией игрока
3. **Разнообразие**: Разные типы оружия имеют уникальные характеристики
4. **Справедливость**: Враги не должны быть слишком лёгкими или слишком сложными

## Формула расчёта урона

```
Финальный урон = (Базовый урон оружия × Модификатор обвесов × Модификатор критического удара) - Броня врага
```

### Модификаторы критического удара
- Обычный выстрел: 1.0x
- Критический удар (голова): 2.0x
- Критический удар (слабое место): 3.0x

# Баланс оружия

## Классификация оружия

### Пистолеты (Побочное оружие)
- **Назначение**: Ближний бой, последнее средство
- **Дальность**: 0-25 метров
- **Темп стрельбы**: Средний
- **Урон**: Низкий-Средний
- **Точность**: Средняя

### Автоматы (Основное оружие)
- **Назначение**: Средняя дистанция, универсальное оружие
- **Дальность**: 0-100 метров
- **Темп стрельбы**: Высокий
- **Урон**: Средний
- **Точность**: Средняя-Высокая

### Снайперские винтовки (Дальнобойное оружие)
- **Назначение**: Дальний бой, точечные удары
- **Дальность**: 50-300 метров
- **Темп стрельбы**: Низкий
- **Урон**: Очень высокий
- **Точность**: Очень высокая

### Дробовики (Ближний бой)
- **Назначение**: Ближний бой, уничтожение групповых целей
- **Дальность**: 0-15 метров
- **Темп стрельбы**: Низкий-Средний
- **Урон**: Очень высокий (на короткой дистанции)
- **Точность**: Низкая

### Пулемёты (Подавление огня)
- **Назначение**: Подавление врагов, уничтожение групповых целей
- **Дальность**: 0-150 метров
- **Темп стрельбы**: Очень высокий
- **Урон**: Средний-Высокий
- **Точность**: Низкая-Средняя

### Гранатомёты (Тяжёлое оружие)
- **Назначение**: Уничтожение групповых целей, укреплений
- **Дальность**: 10-200 метров
- **Темп стрельбы**: Очень низкий
- **Урон**: Экстремальный (AOE)
- **Точность**: Средняя

# Баланс врагов

## Общие принципы

1. **Здоровье врагов** зависит от типа и уровня сложности
2. **Урон врагов** масштабируется с прогрессией игрока
3. **Каждый тип врага** имеет слабые места
4. **Боссы** имеют уникальные механики

## Формула здоровья врагов

```
Здоровье врага = Базовое здоровье × Множитель сложности × Множитель уровня
```

### Множители сложности
- Лёгкий: 0.8x
- Обычный: 1.0x
- Сложный: 1.3x
- Нереальный: 1.6x

### Множители уровня
- Уровень 1: 1.0x
- Уровень 2: 1.2x
- Уровень 3: 1.4x
- Уровень 4: 1.6x
- Уровень 5: 1.8x

# Заключение

Этот документ служит основой для балансировки игры. Все значения могут быть изменены в процессе тестирования и разработки.

**Рекомендации по тестированию:**
1. Тестируйте каждое оружие против каждого типа врагов
2. Проверяйте баланс на разных уровнях сложности
3. Следите за временем убийства врагов (TTK - Time To Kill)
4. Собирайте обратную связь от тестировщиков

**Цели баланса:**
- Средний TTK для обычных врагов: 2-5 секунд
- Средний TTK для элитных врагов: 10-20 секунд
- Средний TTK для боссов: 5-10 минут
- Игрок должен умирать в среднем 3-5 раз на уровне сложности "Обычный"
